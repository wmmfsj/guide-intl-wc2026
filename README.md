# guide-intl-wc2026

本仓库用于归档和发布多个独立的 HTML 页面。这些页面不针对任何特定域名或网站，仅作为通用资料存储与展示用途。

## 项目简介

该项目旨在整理、归档与世界杯（World Cup 2026）相关的信息页面，以独立 HTML 文件的形式存放。每个 HTML 页面可独立访问，内容涵盖赛事指南、赛程概览、球队资料等通用信息。

## 目录说明

仓库根目录下包含若干 `.html` 文件，以及可能的资源文件夹（如 `assets/`、`css/`、`js/` 等）。每个 HTML 文件均为一页独立内容，可直接通过浏览器打开查看。

```
/
├── index.html          # 入口页面（如有）
├── page1.html          # 示例页面
├── page2.html          # 示例页面
├── assets/             # 静态资源目录（可选）
│   ├── images/
│   └── styles/
└── README.md           # 本文件
```

> 实际文件结构以仓库内容为准。

## 页面归档说明

- 每个 HTML 文件均为自包含页面，无需依赖外部服务器或数据库。
- 页面内容可能包含文字、表格、图片链接等基础元素，适合离线查阅或静态托管。
- 所有页面均以世界杯相关主题为背景，但不对应任何官方组织或商业实体。

## 维护说明

本仓库由维护者定期更新，主要用于存档与分享。若发现页面内容有误或链接失效，欢迎提交 Issue 或 Pull Request。由于页面为静态 HTML，修改后可直接替换对应文件。

### 贡献方式

1. Fork 本仓库
2. 创建新分支（`git checkout -b fix/xxx`）
3. 修改对应 HTML 文件
4. 提交并推送（`git commit -m "fix: ..."`）
5. 创建 Pull Request

### 注意事项

- 请勿在页面中添加隐私信息、恶意代码或违反法律法规的内容。
- 若需新增页面，请保持命名清晰，并在根目录下添加相应文件。
